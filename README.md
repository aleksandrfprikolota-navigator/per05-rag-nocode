# Поддержка 1С-Премиум

Сайт компании со встроенным чатом и поиск по материалам: каталог услуг, статьи, контакты и график работы.

## Сайт

Страница лежит в `test-page/index.html`. Чат в правом нижнем углу отвечает по базе знаний компании.

## База

Тексты — в `n8n-v2/data`: описание компании, справочники и статьи.

## Поиск

Загрузка текстов в Pinecone и поиск по ним собраны в `n8n-v2`: два сценария n8n и скрипты `upload_files_to_pinecone.py` и `test_search_api.py`. Как подключить ключи и вебхуки — в [n8n-v2/README.md](n8n-v2/README.md).
